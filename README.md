# 🌱 EcoTech Solutions 💻

Bem-vindo ao **EcoTech Solutions**, um site fictício criado para fins educacionais e para compor um portfólio de desenvolvimento web.

---

## 🔹 Sobre o projeto

Criado por **Ana Vitória Chaves**, o site simula uma empresa moderna de tecnologia focada em:

- 🌍 Sustentabilidade  
- 💡 Inovação tecnológica  
- 🖥️ Soluções digitais inteligentes  

É totalmente fictício, mas desenvolvido com **HTML5 e CSS3**, seguindo boas práticas de organização de arquivos e design responsivo.

---

## 🔹 Funcionalidades

- ✅ Layout moderno e limpo  
- ✅ Navegação por seções: [Home](#home), [Sobre](#sobre), [Serviços](#servicos), [Contato](#contato)  
- ✅ Cards ilustrativos para apresentar serviços  
- ✅ Logo e favicon integrados  
- ✅ Responsivo para diferentes tamanhos de tela
